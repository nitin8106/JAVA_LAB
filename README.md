Object-Oriented Programming in Java

This repository documents my learning journey in Object-Oriented Programming (OOP) using Java.
It includes implementations and examples covering fundamental OOP concepts such as classes, objects, packages, and the four core principles of OOP.

Overview
The purpose of this repository is to build a strong foundation in Java by practicing structured, object-oriented design and understanding how real-world problems can be modeled using OOP concepts.
